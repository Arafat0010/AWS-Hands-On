# AWS Hands-On Projects 🚀

Welcome to my personal collection of hands-on AWS projects. This repository documents my practical learning journey with various AWS services using the AWS Free Tier, CLI, and CloudFormation.

## 📌 About

This repo is meant to:
- Practice real-world AWS use cases
- Document tasks, scripts, and templates I build
- Prepare for AWS certifications (like Cloud Practitioner, Solutions Architect, etc.)
- Help others learn by sharing clean examples
