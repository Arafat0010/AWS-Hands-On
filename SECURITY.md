# Security Policy

## Supported Versions

We release patches for security vulnerabilities in the following versions:

| Version | Supported          |
| ------- | ------------------ |
| latest  | ✅ (actively supported) |
| older   | ❌ (not supported) |

## Reporting a Vulnerability

If you discover a security issue, please **do not open a public issue**.  
Instead, report it responsibly by following these steps:

1. Email us at **arafat.anwar0010@gmail.com** with a detailed description of the issue.  
   - Include steps to reproduce if possible.  
   - Include the potential impact.

2. We will let you know your report within 48 hours.  
3. We aim to provide a fix within **7 days**, depending on severity.  
4. Once resolved, we will publish a security release and acknowledge your contribution (if you want).

## Scope

This policy covers:
- Source code in this repository
- Configuration files
- Deployment templates (if included)

It does **not** cover:
- Third-party dependencies (please report those to the vendor)
- Infrastructure outside this repository

## Responsible Disclosure

Please act in good faith:
- Do not exploit vulnerabilities beyond what is necessary to demonstrate them.  
- Please don't share details publicly until a fix is released.
